DZlog 지원

Android · iOS 공용 도움말
최종 수정일: 2026-11-17
DZlog는 사진 촬영과 동시에 파일 이름, 저장 위치, 표 형태의 기록을 구성해 반복 촬영 업무를 정리하는 앱입니다. 현재 제공되는 기능은 모두 무료로 사용할 수 있습니다.

빠른 시작

  1. 앱을 실행하고 시작 양식 또는 기존 작업 환경을 선택합니다.
  2. 홈 화면에서 촬영을 시작합니다.
  3. 카메라와 사진·저장 권한을 허용합니다.
  4. 파일 이름, 저장 위치와 사진에 표시할 기록값을 확인합니다.
  5. 촬영한 뒤 최근 촬영 또는 기기의 사진·파일 앱에서 결과를 확인합니다.

권한 문제 해결

Android

설정 → 앱 → DZlog → 권한에서 카메라와 사진·미디어 권한을 확인해 주세요. 사용자가 선택한 폴더에 저장하는 기능은 해당 폴더 접근 권한을 다시 선택해야 할 수 있습니다.

iPhone

설정 → 앱 → DZlog에서 카메라와 사진 권한을 확인해 주세요. 사진 저장이나 불러오기가 되지 않으면 사진 접근 범위를 허용한 뒤 앱으로 돌아와 다시 시도해 주세요.

자주 묻는 질문

사진과 기록이 외부 서버로 전송되나요?

아니요. DZlog은 계정, 광고, 분석 기능을 사용하지 않으며 사진과 기록을 개발자 서버로 전송하지 않습니다.

앱을 삭제하면 촬영 사진도 삭제되나요?

앱 내부 설정과 복구용 기록은 일반적으로 함께 제거됩니다. 다만 사진 보관함, 공유 미디어 저장소 또는 사용자가 선택한 폴더에 저장된 사진과 내보내기 파일은 남을 수 있으므로 사진 앱이나 파일 관리 앱에서 직접 삭제해 주세요.

작업 환경을 다른 기기로 옮길 수 있나요?

설정의 작업 환경 내보내기로 백업 파일을 만든 뒤, 새 기기의 가져오기 기능에서 해당 파일을 선택해 주세요. 중요한 작업 전에는 내보낸 파일이 정상적으로 보관되었는지 확인하는 것을 권장합니다.

저장한 사진이 보이지 않아요.

먼저 카메라와 사진·저장 권한을 확인하고, 앱에서 선택한 저장 위치와 기기의 사진 또는 파일 앱을 확인해 주세요. 문제가 계속되면 기종, 운영체제 버전, 재현 순서를 이메일에 적어 보내 주세요.

유료 기능이나 구독이 있나요?

현재 DZlog의 모든 기능은 무료로 제공되며 앱 내 구입과 구독은 없습니다.
